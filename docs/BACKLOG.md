# Бэклог — Almaty Vertical

Фичи, которые не в MVP, но которые мы планируем реализовать.

---

## Генерация рельефа
- [ ] `terrain_generator.gd` — процедурная генерация рельефа из GPX-файлов реальных маршрутов
- [ ] Процедурные препятствия — одна и та же дистанция, но разные камни/корни каждый забег
- [ ] Одна тропа в разное время может быть немного разной — это и генерируем

## Мета-прогрессия
- [ ] Опыт маршрута — ты начинаешь знать где опасные участки
- [ ] Разблокировка новых персонажей
- [ ] Разблокировка новых маршрутов
- [ ] Сход с дистанции сохраняет прогресс пропорционально пройденному

## Персонажи
- [ ] **Дизель** — отличный подъём, медленный спуск
- [ ] **Техник** — безопасный спуск, слабая выносливость
- [ ] **Спринтер** — очень быстрый, силы кончаются быстро
- [ ] Система выбора персонажа перед забегом
- [ ] `CharacterData.tres` ресурс для хранения статов

## Маршруты
- [ ] **Кок-Жайляу** — средний, первые серьёзные подъёмы
- [ ] **Кумбель** — длинный, смешанный рельеф
- [ ] **БАО (Большое Алматинское Озеро)** — эпик, финальный маршрут
- [ ] Система чекпоинтов каждые 30 секунд

## Выживание (длинные маршруты)
- [ ] Еда/вода — ресурс на длинных дистанциях
- [ ] Смерть "Стена" — не нашёл еду/воду вовремя

## Полировка
- [ ] Звуковое оформление
- [ ] Музыка
- [ ] Анимации: run, jump, fall, slide_down
- [ ] Подключение пиксельных ассетов (спрайтшиты)
