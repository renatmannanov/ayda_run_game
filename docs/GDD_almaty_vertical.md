# 🏔️ Almaty Vertical — Game Design Document
*Trail Running Roguelite | v0.1 | Renat, 2026*

---

## Концепция в одной фразе
Бегун бежит по горному маршруту сам — ты управляешь усилием и телом. Неправильно распределил силы на рельефе — умер. Попробуй снова.

## Референсы
- **Celeste** — платформер где учишь уровень через смерти, точное управление
- **Risk of Rain 1** — нарастающий хаос, рогалик-прогрессия
- **Canabalt / Alto's Adventure** — авторан с минималистичным управлением
- **Дино-игра Chrome** — feel автобега с препятствиями

## Основная механика

### Движение
- Персонаж бежит **автоматически** вправо
- Игрок управляет тремя действиями:
  - `↑ / Space` — прыжок / карабкание
  - `→ / Shift` — ускорение (газ)
  - `↓ / S` — сбросить темп (тормоз)

### Две ключевые шкалы
| Шкала | Что делает | Когда кончается |
|-------|-----------|-----------------|
| **Силы (Stamina)** | Тратится на подъёмах и ускорении | Персонаж падает, теряет темп |
| **Суставы (Joints)** | Бьётся на жёстких спусках и прыжках | Травма → конец забега |

### Рельеф — главный враг
- Крутой подъём → жрёт Силы быстро
- Крутой спуск → бьёт Суставы если не сбросил темп (урон только при скорости > 250 px/s)
- Ровный участок → восстановление Сил
- Камни/корни → случайный obstacle; столкновение = потеря скорости + лёгкий урон по Суставам

### Препятствия — итеративный дизайн
- **Камни/корни:** пока столкновение = потеря скорости + урон по Joints (10-15). Точный баланс через плейтесты.
- **Прыжок** через препятствие тратит Stamina (5-8) — бегун в горах не прыгает легко, это реалистичный выбор: прыгнуть (быстро, но дорого по силам) или затормозить и обойти (медленно, но безопасно).
- Будем тестировать разные варианты и итерировать.

### Способы умереть
1. **Закислился** — Силы упали до нуля на подъёме
2. **Убил колено** — слишком быстро на спуске без торможения
3. **Споткнулся** — столкнулся с препятствием при высокой скорости (потенциально — позже)
4. **Стена** — на длинном маршруте не нашёл еду/воду (позже)

### Сойти с дистанции (не смерть)
- Можно сознательно выйти в любой точке (Esc)
- Сход ≠ смерть, нет штрафа
- Прогресс (опыт маршрута) сохраняется пропорционально пройденному расстоянию
- Дизайн-идея: не наказывать игрока за осторожность, поощрять пробовать снова

### Генерация рельефа (будущее)
- **MVP:** уровни hand-crafted (как Celeste)
- **Позже:** основной профиль маршрута генерируется из GPX-файлов реальных трейлов
- Препятствия (камни, корни, ручьи) — процедурные, т.к. даже одна тропа в разное время разная
- Одна и та же дистанция — знакомый рельеф, но новые препятствия каждый раз

## Прогрессия (рогалик)

### Маршруты (порядок сложности)
1. **Фурманова** — короткий, простой рельеф, обучение
2. **Кок-Жайляу** — средний, первые серьёзные подъёмы
3. **Кумбель** — длинный, смешанный рельеф
4. **БАО (Большое Алматинское Озеро)** — эпик, финальный маршрут

### Персонажи (разблокируются)
| Персонаж | Сильная сторона | Слабость |
|----------|----------------|---------|
| **Алматинец** (стартовый) | Сбалансирован | Нет особых |
| **Дизель** | Отличный подъём | Медленный спуск |
| **Техник** | Безопасный спуск | Слабая выносливость |
| **Спринтер** | Очень быстрый | Силы кончаются быстро |

### Мета-прогрессия
- Каждый забег даёт **Опыт маршрута** — ты начинаешь знать где опасные участки
- Разблокируются новые персонажи
- Открываются новые маршруты

## MVP (первые 2 недели)

**Цель MVP:** один маршрут, один персонаж, базовые механики работают и уже весело

### Неделя 1 — Бег и выносливость
- [ ] Структура проекта, project.godot, input map
- [ ] Авторан персонажа по тайловому уровню (CharacterBody2D)
- [ ] Управление: газ/тормоз/прыжок
- [ ] Шкала Сил (Stamina) — тратится на подъёмах и ускорении
- [ ] Тестовый уровень: ровный → подъём → ровный → подъём
- [ ] HUD: шкала Stamina + скорость (для отладки)
- [ ] Смерть "Закислился" при Stamina = 0

### Неделя 2 — Суставы, спуски, препятствия
- [ ] Шкала Суставов (Joints) — бьётся на быстрых спусках
- [ ] Тестовый уровень расширен: + спуски + камни
- [ ] Препятствия (камни/корни) — столкновение и прыжок
- [ ] Экран смерти с причиной
- [ ] Полный маршрут Фурманова ~3 минуты
- [ ] Параллакс горный фон
- [ ] Камера со смещением вправо (видеть рельеф впереди)

**Не в MVP:**
- Несколько персонажей
- Мета-прогрессия
- Еда/вода
- Звук
- Процедурная генерация / GPX
